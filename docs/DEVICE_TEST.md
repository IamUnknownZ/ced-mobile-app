# บันทึกทดสอบอุปกรณ์

ยังไม่มีผลจากอุปกรณ์จริง กรุณาบันทึก: วันที่, รุ่นโทรศัพท์, OS, เวอร์ชัน Expo Go/development build, ผลแสดงกล่องและดาว, ค่าดิบ Gyroscope, ทิศหมุนซ้าย/ขวา/ขึ้น/ลง, drift เมื่อวางนิ่ง, ผลตั้งศูนย์, หลังเข้า background และกลับมา, การเล็ง/เก็บ/คัดแยก/จบด่าน, ภาพหน้าจอและข้อผิดพลาด

การ export Android เป็นเพียงการตรวจ bundle ไม่ยืนยัน native renderer หรือเซนเซอร์ทำงานจริง

## ความเข้ากันได้หลายอุปกรณ์

หน้าทดสอบปรับความไว 0.50–3.00× กลับทิศแกน และตั้งศูนย์ได้ ค่าเก็บในเครื่องและใช้ร่วมกับด่านสวน เริ่มค่า 1.30× การกรองใช้เวลาตามช่วง sample แทนสมมติว่าอุปกรณ์ส่งข้อมูลถี่เท่ากัน หากไม่มีเซนเซอร์มีปุ่มทดลอง แอปตั้งแนวตั้ง แต่การล็อกแนว iPad แบบ multitasking และการตอบสนองของแต่ละรุ่นต้องยืนยันบนเครื่องจริง

รายการทดสอบที่ยังรอ: iPhone, iPad, Huawei MatePad 11.5 S และ vivo T1 5G — ตรวจรุ่น OS, Expo Go ที่ตรง SDK, sensor permission, การหมุนแต่ละแกน/ตั้งศูนย์, หน้าจอและ safe area, ความต่อเนื่องหลังพักแอป, FPS และความร้อน; ไม่มีผลทดสอบสำหรับเครื่องเหล่านี้ในขณะบันทึกนี้

แนวควบคุมทดสอบแบบจอแนวตั้ง: เอียงซ้าย–ขวาใช้แกน z และเอียงขึ้น–ลงใช้แกน x; ปุ่มกลับทิศใช้ปรับตามเครื่องและความถนัด ต้องยืนยันการเคลื่อนจริงบน iOS และ Android ยังไม่สรุปว่าทิศตรงทุกเครื่อง

หน้าตรวจระบบสลับแกนแนวนอนได้ระหว่างเอียงเครื่อง (z) กับหมุนเครื่อง (y); ใช้ค่านี้ร่วมกับด่านสวนและบันทึกในเครื่อง ทดสอบซ้ายและขวาหลังตั้งศูนย์ทั้งสองโหมด เทียบมุมที่แสดง ค่าเพิ่มและลดได้ และตรวจความรู้สึกกับเครื่องจริงก่อนเลือกค่าเริ่มต้นถาวร

การปรับล่าสุดตั้งค่าแนวนอนเริ่มต้นเป็นหมุนเครื่องซ้าย–ขวา (แกน y) ตามผลทดลองของผู้ใช้ โดยย้ายค่าตั้งเดิมครั้งเดียวและคงความไว/การกลับทิศไว้ ผู้เล่นยังสลับไปเอียงเครื่อง (แกน z) ได้ ต้องทดลองยืนยันบนมือถือจริงอีกครั้ง

## ทดสอบการปรับเทียบ Beta candidate

ในหน้าตั้งค่าการหมุน วางเครื่องให้นิ่งและกดปรับเทียบ รอผลสำเร็จ; ลองเขย่าในระหว่างปรับเทียบเพื่อยืนยันระบบปฏิเสธ; หลังสำเร็จตรวจว่าการเล็งเมื่อวางนิ่งไม่ไหล และหันไปกลับได้ทั้งสองทิศ จากนั้นปิด–เปิดแอปเพื่อตรวจว่าค่ายังคงอยู่ ลองเปิด/ปิดเพลงและเอฟเฟกต์ พักแอปแล้วกลับมา ตรวจเสียงซ้ำบน Android และ iOS ทั้งลำโพง/หูฟัง

## ทดสอบการสำรวจรอบดาวและแตะขยะ

โหมดสำรวจเร็วเป็นตัวคูณการหมุนจากเซนเซอร์ 3 เท่าเพิ่มเติมจากความไวที่ผู้เล่นตั้งไว้ ปิดเป็น 1 เท่าได้ในด่าน ใช้ปุ่มพักหมุน จัดท่ามือใหม่ แล้วกดหมุนต่อโดยไม่ควรเกิดการกระโดด การตั้งศูนย์กลับมุมมองเริ่มต้น; ไม่ได้ใช้ท่ามือแทน Gyroscope หรือบังคับให้หมุนตัว

เล็งให้วงกลางตรงขยะที่มองเห็น แล้วแตะตำแหน่งต่าง ๆ ในพื้นที่ดาว ต้องเปิดข้อมูลของขยะที่เล็ง เมื่อไม่ได้เล็งขยะ การแตะต้องไม่เปิดข้อมูล และเล็งของหลังดาวไม่ได้ การทดสอบ touch/การบัง/ความสบายบนเครื่องจริงยังรอผู้เล่น
