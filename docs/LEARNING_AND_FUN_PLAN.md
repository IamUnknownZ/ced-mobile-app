# แผนการเรียนรู้และความสนุก — Planet Cleaner

ใช้หลักสอน → ทดลอง → รับผล → ทบทวน โดยอ้างอิงภาพ 01–10 และขอบเขตด่านใน AGENTS.md ร่วมกับ `game-ui-ux`, `game-feel`, `level-design` จากชุด awesome-gamedev-agent-skills แผนนี้เป็นข้อเสนอสำหรับพัฒนาต่อ ไม่ใช่ผลทดสอบกับผู้เล่น

| ช่วง | ผู้เล่นทำอะไร | สิ่งที่ควรเรียนรู้ | หลักฐาน/เงื่อนไขตรวจ |
|---|---|---|---|
| แนะนำ | ถือเครื่องนิ่ง ตั้งศูนย์ และลองเล็ง | ควบคุมโดยไม่ต้องเดินหรือหมุนตัว | ผู้เล่นใหม่เล็งเป้าหมายแรกเองได้; บันทึกเวลาและข้อสับสน |
| ทดลอง | พบขยะ เห็นชื่อ/รูปร่าง แล้วเลือกประเภท | ทดลองจำแนกก่อนเห็นคำเฉลย | modal ก่อน quiz ไม่แสดงหมวดหรือเหตุผล |
| Feedback | ดูผล คำอธิบาย และวิธีจัดการ | รู้เหตุผลและขั้นตอนถัดไป ไม่ใช่จำสีถัง | ถูกและผิดมีคำอธิบายสั้น พร้อมหมายเหตุเรื่องท้องถิ่น |
| ทบทวน | เปิดคู่มือสิ่งที่ค้นพบ | กลับมาดูความรู้ได้โดยไม่ขัดจังหวะเกม | ค้นหา/กรองได้ ข้อมูลตรงกับ quiz |
| ปิดด่าน | ดูผลและเล่นซ้ำได้ | เห็นความคืบหน้าและจุดที่ยังต้องฝึก | คะแนน ความแม่นยำ และเวลามาจากผลเล่นจริง |

## ออกแบบความสนุก

ให้เป้าหมายมองเห็นชัดและแตะวงเล็งได้ทันที; เมื่อตอบถูกให้ feedback สั้น ชัดและไม่บังการเล่น; เมื่อตอบผิดให้ลองใหม่ได้โดยไม่ลงโทษซ้ำไม่สิ้นสุด; สลับช่วงสำรวจกับช่วงตอบเพื่อให้พักสายตา และหลีกเลี่ยงการสั่น/กระพริบหรือภาพสั่นรุนแรงที่ทำให้เวียนหัว การเพิ่มเติมเสียง/สั่นต้องมีตัวเลือกปิดและตรวจบนอุปกรณ์จริง

## วิธีตรวจ

ทดสอบอย่างน้อยผู้เล่นใหม่หนึ่งคนโดยไม่อธิบายปุ่มก่อน: จับเวลาเล็งและเก็บชิ้นแรก, บันทึกการกดผิด/ความสับสน, ทดลองคำตอบผิดและการตั้งศูนย์, ถามว่าผู้เล่นอธิบายเหตุผลการแยกได้หรือไม่ และให้คะแนนความสนุก/ความสบายหลังเล่น ไม่ตีความว่าได้ผลจนมีบันทึกการทดสอบจริง

## งานรอเพื่อนร่วมทีม

ข้อความการสอน, ตัวอย่างขยะ, คำอธิบาย/แหล่งข้อมูล และหน้าจอเพิ่มเติมที่เพื่อนรับผิดชอบยังรอส่ง ตรวจความถูกต้องตามท้องถิ่นและปรับผ่าน shared contracts ก่อนรวม ไม่สมมติว่าได้รับหรืออนุมัติเนื้อหาแล้ว ดู `WORK_SPLIT.md` และ `CONTENT_SOURCES.md`
