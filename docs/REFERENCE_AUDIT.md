# ตรวจภาพอ้างอิง

ตรวจภาพทั้ง 11 ภาพจาก `reference_images` แล้ว (รวมภาพ gameplay เสริม) ภาพเป็นแนวตั้ง ท้องฟ้าสีฟ้า แสงนุ่ม โลกจิ๋ว low-poly สีเขียว/ฟ้า/เหลือง ป้ายไม้ ตัวอักษรหนาโค้งมน การ์ดสีอ่อนมุมมน ปุ่มใหญ่มีขอบและเงา องค์ประกอบสำคัญเว้นระยะจากขอบจอ

| ไฟล์ | หน้าจอและสิ่งที่เห็น | สิ่งที่ต้องทำจริง / ความต่างที่ยอมรับได้ |
|---|---|---|
| 01_Main_Menu.jpg | โลโก้ด้านบน ดาวครึ่งสะอาดครึ่งสกปรกกลางจอ ปุ่มเริ่มสีส้มและปุ่มรองสามปุ่มด้านล่าง | เมนูใช้งานจริง; ดาวสร้างจริงหลังอนุญาต ไม่ใช้ภาพทั้งหน้า |
| 02_Level_Select.jpg | การ์ดฉาก 2×2 มีดาวและแถบ progress ปุ่มเริ่มด้านล่าง | เลือกสี่ด่านและแสดงสถานะจริง; ปรับขนาดการ์ดตามจอ |
| 03_How_To_Play.jpg | การ์ดสีฟ้าสี่ขั้นแนวตั้ง ภาพประกอบและปุ่มสีเขียว | อธิบาย gyro เล็ง เก็บ แยก และเริ่มเล่นได้ |
| 04_Gameplay_School.jpg | โลโก้/HUD บน ดาวโรงเรียนกลาง วงเล็งกลาง ปุ่มเก็บสีส้มและแถบเครื่องมือด้านล่าง | ฉาก 3D จริง HUD และปุ่มทำงาน; องค์ประกอบฉากปรับตามประสิทธิภาพ |
| 05_Item_Info.jpg | ฉากมืดลง การ์ดข้อมูลถ่าน ปุ่มเก็บ/ข้อมูล | modal จริง; ภาพตัวอย่างเฉลยประเภทก่อน quiz จึงต้องซ่อนประเภทและเหตุผลจนตอบ |
| 06_Sorting.jpg | คำถามบน ขวดตรงกลาง ถังสี่ใบด้านล่าง มาสคอตใบไม้ | เลือกถังด้วยการแตะ คำใบ้ไม่เฉลย; มาสคอตเป็นทางเลือก |
| 07_Correct_Feedback.jpg | หัวข้อสีเขียว ขวดไปถัง เกร็ด คะแนน combo และปุ่มต่อ | แสดงผลจากคะแนนและคำตอบจริง ไม่ยึดสีถังที่ขัดกับภาพอื่น |
| 08_Incorrect_Feedback.jpg | หัวข้อแดง การ์ดเปรียบเทียบถังผิด/ถูก คำอธิบายและปุ่มสองปุ่ม | แสดงเหตุผลและควบคุมการลองใหม่ตามกติกาจริง |

| 10_Level_Results.jpg | ภาพก่อน/หลังกลางจอ การ์ดคะแนน เวลา ความแม่นยำ ดาว ปุ่มสามปุ่มล่าง | คำนวณสรุปจริง; ภาพก่อน/หลังต้องสะท้อนสถานะจริง |
