## แก้ผลตอบผิดและเพิ่มรายละเอียดดาว

ตามความเห็นผู้ใช้ หน้าตอบผิดต้องสื่อด้วยสีแดงอย่างชัดเจน จึงแยกกรอบ การ์ดตัวเลือกที่ผิด พื้นความรู้ ไอคอน และปุ่มลองอีกครั้งจากหน้าตอบถูก ส่วนฉาก 3D เพิ่มผืนดินที่เห็นชายฝั่ง น้ำ หิน พุ่มไม้ ทางเดิน และแลนด์มาร์กของแต่ละพื้นที่ องค์ประกอบนี้ยังห่างจากความหนาแน่นและคุณภาพภาพเป้าหมาย ต้องตรวจบนอุปกรณ์จริงก่อนอ้างว่าตรงแบบ

เพิ่มพุ่มไม้/ต้นไม้ซ้ำด้วย instanced mesh เพื่อให้ผิวดาวไม่โล่ง โดยเพิ่ม draw call คงที่สำหรับกลุ่มนี้แทนการสร้าง mesh แยกทุกต้น ยังต้องดูผลจริง เพราะภาพอ้างอิงมีรายละเอียดจำนวนมากกว่าและอุปกรณ์แต่ละรุ่นมีงบเรนเดอร์ไม่เท่ากัน

## 3D model pass and user-requested performance reduction

Rebuilt four scenes as raised low-poly islands with authored landmarks, paths, coastline, props and 15 waste silhouettes. User reported the dense iteration lagged and asked for less detail. Reduced the final model previews to 7,080–8,440 triangles, switched to Lambert shading and a simple key/hemisphere rig, and separated picking into a hidden hull under 450 triangles. See `docs/visual-qa/3d-mobile/README.md` and screenshots for the final lightweight direction. These are actual geometry renders, not native gameplay screenshots. Physical-device frame rate is still unmeasured.
