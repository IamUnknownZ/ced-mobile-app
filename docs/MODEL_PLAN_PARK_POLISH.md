# แผนปรับโมเดลสวนชุดถัดไป — รออนุญาต

ภาพเป้าหมาย: `reference_images/01_Main_Menu.jpg`, `02_Level_Select.jpg`, `04_Gameplay_School.jpg`, `11_Extra_Gameplay_Overview.jpg`. ฉากสวนปัจจุบันเป็นต้นแบบรูปทรงเรียบ ยังไม่ใกล้รายละเอียดของภาพ

ชุดที่จะปรับหลังได้รับอนุญาต: ดาวสวนและผิว/ทางเดิน; ต้นไม้และไม้พุ่ม; ม้านั่งและถัง/พร็อพสวน; ขยะ 8 ชนิดที่มีอยู่ให้มี silhouette และสีที่แยกได้ชัด โดยคงข้อมูลและระบบเล็งเดิม ใช้ geometry และวัสดุซ้ำเมื่อเหมาะสม ตรวจจุดหมุน ขนาดและความลื่นบนมือถือจริง

ชุดนี้ไม่รวมโมเดลโรงเรียน ชายหาด ชุมชน ตัวละคร หรือเนื้อหาที่รอเพื่อนร่วมทีม และยังไม่มีการแก้โมเดลในชุดนี้
