# แผนโมเดล Phase 3 — รออนุญาต

ชุดแรกสำหรับ vertical slice ในสวน: ดาวทรงกลม low-poly พร้อมพื้นหญ้า/ทางเดิน, ต้นไม้, ม้านั่งและถัง/พร็อพเล็กน้อย และขยะ 8–10 รูปทรงที่แยกมองเห็นได้ ครอบคลุมทั่วไป รีไซเคิล อินทรีย์ อันตราย เช่น ซองขนม กระดาษเปื้อน ขวดพลาสติก กระป๋อง กระดาษสะอาด เปลือกกล้วย ใบไม้ ถ่านไฟฉาย อาจใช้ geometry ที่ซ้ำกันและ material ร่วมเพื่อรักษาประสิทธิภาพ

ใช้ procedural Three.js เมื่อเหมาะสม รูปทรงต้องมีสเกลและจุดกำเนิดที่เหมาะสำหรับวางบนดาว มี collision/targeting เป็นคนละระบบและไม่อนุญาตให้เก็บผ่านดาว ตรวจด้วย renderer และอุปกรณ์จริง รูปทรงกล่องในหน้าตรวจเป็นเพียง debug ชั่วคราว ไม่ใช่ asset

ชุดนี้ไม่รวมฉากโรงเรียน ชายหาด ชุมชน หรือสัตว์ ซึ่งต้องขออนุญาตแยกเมื่อถึงชุดงานนั้น
