# Planet Cleaner: หมุนโลก แยกขยะ

เกมมือถือแนวตั้ง ผู้เล่นเป็นผู้พิทักษ์ดาว สำรวจดาวด้วยการขยับมือถือ เล็งขยะ กดเก็บ เลือกถัง รับคำอธิบาย คะแนน และเห็นดาวฟื้นฟู จบเมื่อเก็บครบ

ลำดับ: เมนู → เลือกด่าน → สำรวจ/เล็ง → เก็บ → เลือกประเภท → ผลถูกหรือผิด → สำรวจต่อ → สรุปผล มีสวน โรงเรียน ชายหาด ชุมชน และขยะทั่วไป รีไซเคิล อินทรีย์ อันตราย

Gyroscope เป็นตัวควบคุมหลัก พร้อมตั้งศูนย์ ความไว และโหมดทดลองที่ติดป้ายชัดเจน เลือกถังด้วยการแตะ ต้องไม่เก็บเป้าหมายหลังดาว UI ภาษาไทย ไม่มี backend ผู้เล่นหลายคนหรือตัวละครเดิน คะแนน/การลองใหม่และรายละเอียดการสอนต้องตรงข้อกำหนดใน AGENTS.md

เป้าหมายแรก: หนึ่งด่านเล่นครบวงจรแล้วขยาย โดยทุกโมเดล 3D จริงต้องได้รับอนุญาตก่อนสร้างหรือแก้ไข
